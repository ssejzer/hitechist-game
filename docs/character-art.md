## In-game likeness

Gameplay uses pre-generated transparent 48-pixel head sprites in `public/assets/faces/`. Each character has one 4-by-2 PNG sheet with frames ordered: focused, happy, blink, wink, surprised, grumpy, worried, hurt. The sheets were generated with the built-in imagegen tool from the matching roster portraits, using a flat magenta background, then keyed and packed into transparent frames. The renderer selects the frame from the existing expression animation; the native Canvas face remains a loading fallback. Walking and collision bounds are unchanged.

Elad's dog and Nenad's black cat use transparent four-pose pixel-art sheets in `public/assets/companions/`. The dog was generated from the supplied dog reference photo; the cat was generated from its description. Both follow their engineer visually, sit when idle, and ride out of view during shuttle travel. Erez has a slim body silhouette, Nenad has a broad one, and Jason has a cigarette with looping smoke. These character details do not change gameplay collision or abilities.

Generation prompt used for each sheet (with the matching portrait as Image 1 and the character's identifying features filled in):

> Use case: style-transfer. Asset type: pixel-art facial animation sprite sheet for an isometric arcade game. Image 1 is identity reference for [name]; preserve [hair, facial hair, glasses or hat, skin tone]. Produce exactly 8 head-and-short-neck-only frames in a strict 4-column by 2-row grid. Same character, same forward-facing pose, same size and position in every cell. Top row left to right: focused/neutral, happy, blink with both eyes closed, wink with right eye closed. Bottom row: surprised open mouth, grumpy frown, worried, hurt with shut eyes. Authentic crisp 16-bit pixel art, chunky square pixels, limited palette, bold dark contours, readable facial gestures at 48 pixels. Each frame must have a flat solid pure magenta #ff00ff background, no checkerboard and no transparency; leave a small consistent margin around complete head. No body, no shoulders, no text, no labels, no grid lines, no other objects.
